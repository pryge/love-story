# Notion Report Instructions

Whenever the user asks "зроби звіт для Notion", "звіт Notion", "звіт для ноушн", or similar:

1. **Update `DEV_LOG.md`**:
   - Mark the completed session as `Done ✅`.
   - Add a new row and section for the next session draft marked as `In Progress ⏳`.

2. **Generate Output for Notion**:
   Output TWO concise report blocks in Ukrainian ready to copy-paste into Notion:

   ---
   ### 🟢 1. Звіт за САМЕ ЗАРАЗ (Status: Done ✅)
   - **Name**: `Сеанс [№] ([Дата]) — [Короткий заголовок]`
   - **Date**: `[Дата]`
   - **status**: `Done ✅`
   - **Modules**: `[Теги]`
   - **Resume File**: `[Файл]`
   - **Page Body**: Дуже коротко основні реалізовані моменти.

   ---
   ### ⏳ 2. Заготовка на НАСТУПНИЙ РАЗ (Status: In Progress ⏳)
   - **Name**: `Сеанс [№+1] ([Дата]) — [Короткий заголовок наступної фічі]`
   - **Date**: `[Дата або пропуск]`
   - **status**: `In Progress ⏳`
   - **Modules**: `[Теги на наступний раз]`
   - **Resume File**: `[Файл з якого почнемо]`
   - **Page Body**: 1-2 короткі тези, що конкретно робиться.

**Important**: Keep all text EXTREMELY concise. No verbose explanations or local OS file links (`file:///...`).
